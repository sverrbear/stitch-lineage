# Logo assets

SVG marks used by the Phase 1 UI as manager badges on lineage/ERD nodes (SPEC.md §9).
The mark answers who *manages* the asset, not which system it happens to sit in:

- `dbt.svg` — dbt mark, brand color `#FF694B` — the dbt pipeline produces this
- `snowflake.svg` — Snowflake mark, brand color `#29B5E8` — a source table, landed in
  the warehouse by something else, so nothing in the dbt repo manages it
- `metabase.svg` — Metabase mark, brand color `#509EE3` — the BI side

Sourced from [Simple Icons](https://simpleicons.org) (CC0). The marks are trademarks of
dbt Labs, Inc., Snowflake Inc. and Metabase, Inc. respectively, used nominatively to
indicate who manages a data asset — no affiliation or endorsement implied.
